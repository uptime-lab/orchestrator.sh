    What it is for

    Install, reach and repair Raspberry Pi boards without going to them.

    • What you can do
    • Who uses it
    • Start

    A Raspberry Pi is easy to set up on a desk and hard to look after once it is somewhere else. Uptime Orchestrator makes the board ask a server on every boot, so you can fix it from a browser.

    What you can do

    • Install an operating system on a board with an empty or broken drive.
    • Open a root terminal when SSH is gone.
    • Back up a drive and restore it.
    • Set users, keys and software once for a group of boards.
    • Run steps on many boards, by hand or on a schedule.

    The board connects out to the server, so it works behind a home router or a customer's firewall.

    Who uses it

    • One board. A home server or a Pi at a relative's house. When it stops booting, reinstall it from your browser.
    • A homelab or a cluster. Reinstall a node instead of debugging it. Capture a configured board and install its image on the next one.
    • A classroom. Put every board back to the same image before the next class.
    • Kiosks and screens. Displays in cafés, shops and airports. Each site is a unit, and its boards keep the kiosk software installed.
    • A company's devices. Roles, single sign-on, an audit trail and an API. The server can run on your own machine.
